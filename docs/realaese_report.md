## 🐛 Bugs Fixed

1. **Transaction Edit Modal Save / Pop Issue**:
   * **Root Cause**: `_submit()` in `AddTransactionBottomSheet` was not setting an active saving flag, allowing duplicate taps. In addition, callback handlers were triggering duplicate `updateTransaction` calls on `transactionsProvider` without `await` synchronization, causing state updates to fire out-of-order before `Navigator.pop(context)` could run.
   * **Fix Applied**: Added `_isLoading` state guard in `AddTransactionBottomSheet`, `AddBudgetBottomSheet`, `CreateGoalSheet`, `EditGoalSheet`, `AddSubscriptionSheet`, `AddToGoalSheet`, and `AddSavingsGoalBottomSheet`. Handled `await` write completion, button loading spinner, and safe `if (mounted) Navigator.of(context).pop()` execution.

2. **Unawaited Provider Reloads**:
   * Synchronized async writes in `subscription_provider.dart` and `add_to_goal_sheet.dart` to await repository writes before popping modal forms.
