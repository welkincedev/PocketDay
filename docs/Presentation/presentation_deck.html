07. Dashboard Architecture

Reactive In-Memory Metric Engine

⚡ In-Memory $O(N)$ Computation

DashboardNotifier listens to transaction and budget streams via Riverpod's ref.listen(), updating net balance and metrics dynamically without issuing Firestore aggregate queries.

📊 Real-Time Financial Indicators

Calculates Total Balance ($Income - Expense$), Safe Daily Spend allowance, Survival Runway days, and renders daily spending velocity via fl_chart.

🎯 Budget & Subscriptions Integration

Tracks category-level spending progress and automatically processes recurring subscription payments on due dates.

08. Engineering Challenges

Practical Code Solutions & Learnings

Verified Code Challenges

  • Preventing Firestore Read Costs: Implemented ref.listen() to compute totalBalance in memory in $O(N)$ time instead of expensive backend aggregations.
  • Splash Frame-1 Timing: Resolved 10ms route pops by enforcing a concurrent 3s presentation window via Future.wait().
  • Double-Tap OAuth Guard: Added if (isLoading) return; guards to block duplicate auth submissions during Google sign-in.
  • Android Task Manager Branding: Configured standard @mipmap/ic_launcher XML adaptive icons across all density buckets.

Key Engineering Learnings

  • Reactive State Design: Combining Riverpod providers for responsive, decoupled state propagation.
  • Local-First Storage: Harnessing Cloud Firestore's native offline cache for 0ms UI startup latency.
  • Production Defensiveness: Implementing lazy loading (IndexedStack) and unawaited background profile synchronization.
